# PR128 Release Notes

PR128 adds deterministic architecture detection over Atlas semantic snapshots.
It identifies layered, modular-monolith, microservices, hexagonal, clean,
CQRS, event-driven, and plugin architectures with confidence and traceable
evidence.

The report also exposes dependency direction, cycles, bounded contexts,
ports/adapters, and infrastructure layers without reading raw source or
replacing existing graph components.
