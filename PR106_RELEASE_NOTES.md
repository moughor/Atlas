# PR106 Release Notes

PR106 publishes Atlas’s explicit plugin threat model. It distinguishes the
implemented opt-in integrity and permission admission gates from controls Atlas
does not claim, including process isolation, runtime capability enforcement,
publisher signatures, protected trust storage, and denial-of-service
containment.

The guide includes secure deployment recommendations, time-of-check/time-of-use
risk, trust assumptions, and future hardening directions. PR60 documentation
now carries a prominent link and boundary warning.
